## 🚀 Quick Start

### First Time Using It?

1. **Open Analytics** → Click "My Analytics" from any page
2. **See Overview** → Dashboard shows your summary
3. **Explore Pages** → Click sidebar links to explore
4. **Filter Data** → Use date filters if needed
5. **Export Data** → Download as CSV whenever you want

## 🔧 How to Use Features

### Change Date Range

**Step 1:** Look at the left sidebar
```
📅 DATE RANGE
[Start Date Input]
[End Date Input]
[Apply] [Reset]
```

**Step 2:** Click the date inputs and pick your dates

**Step 3:** Click "Apply" → Dashboard updates instantly

**Step 4:** To go back to default → Click "Reset"

### Export Your Data

**Option A - From Sidebar:**
1. Click "📥 Export as CSV" button
2. File downloads to your computer

**Option B - From Settings Page:**
1. Click Settings & Export in sidebar
2. Click export button
3. File downloads

**CSV File Contains:**
- Your summary metrics
- Spending totals
- Recent order details
- Everything you see on dashboard

### Move Between Pages

**Click any link in the sidebar:**
```
| 📈 Dashboard Overview
| 💰 Spending Analysis      ← Click here
| 🏪 Vendor Insights
| 🍕 Food Preferences
| 🕐 Ordering Patterns
| 📦 Recent Orders
| ⚙️ Settings & Export
```

That's it! Page changes instantly. No waiting for page reload.

### On Mobile/Tablet?

1. Look for **☰ button** (hamburger menu) in top-right
2. Click it to open sidebar
3. Click page you want
4. Menu closes automatically
5. Sidebar appears at bottom on very small screens

## ❓ Common Questions

**Q: Where's my old analytics page?**
A: Still there! But the new one is better. Old file: `analytics.html`

**Q: Will my data be lost?**
A: No! All your data is safe. Nothing changes except the layout.

**Q: Can I go back to the old design?**
A: Yes, but why would you? 😊 The new design is faster and easier.

**Q: Do the numbers change if I change the date range?**
A: Yes! If you select January-March, you'll only see data from those months.

**Q: When does data update?**
A: Real-time! As soon as you place an order, it appears in your analytics.

**Q: Can I compare with other users?**
A: Not yet, but that's coming in a future update!

**Q: What if nothing shows up?**
A: You might not have orders yet. Place a few orders and check back!

## 🐛 Something Not Working?

### Page Won't Load
- Try refreshing browser (F5)
- Check your internet connection
- Clear browser cache

### Charts Not Showing
- Try different date range
- Refresh the page
- Try different browser

### Data Looks Wrong
- Make sure date range is correct
- Try clicking "Reset" to use default dates
- Check if you're logged in

### Can't Click Links
- Make sure you waited for page to fully load
- Try clicking a different page first
- Refresh the page
