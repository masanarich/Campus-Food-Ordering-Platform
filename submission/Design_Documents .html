System Architecture Diagram

Three-tier architecture showing the client layer (HTML/CSS/JS served via Firebase Hosting), the Firebase backend layer (Auth, Firestore, Storage, Cloud Functions), and third-party integrations (Paystack, Email). Open Food Facts is referenced as a dietary/allergen standardisation framework — not a live API integration. Arrows represent data/request flow; dashed arrows represent webhooks/callbacks.

Activity Diagram
